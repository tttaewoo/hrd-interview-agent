# HRD 인터뷰 요약 Skill v2.0 — 질문·답변 중심

## 이번 개정 내용
- 질문의 순서와 수를 유지하고 각 질문 밑에 대상자별 응답을 문단형으로 정리합니다.
- 지나친 축약을 지양하며 이유, 구체적 사례, 예외, 제안까지 반영합니다.
- 종합 핵심 요약/조치사항은 기본 본문이 아닌 선택 부록으로 분리합니다.
- 참고 문서: 사용자가 제공한 '마케팅 직무 AI 활용 과정(1차수)_사후 인터뷰 정리.docx'의 **내용 흐름**을 참고하였으며, 디자인과 문장까지 복제하는 템플릿은 아닙니다.

## Codex 프로젝트 적용
1. ZIP을 해제합니다.
2. `.agents/skills/hrd-interview-summary` 디렉터리를 Codex 프로젝트 루트의 `.agents/skills/` 아래에 배치합니다.
3. 인터뷰 녹취 텍스트/문서를 프로젝트에 넣거나 대화에 첨부합니다.
4. 아래와 같이 요청합니다.

```
$hrd-interview-summary
이 인터뷰를 질문별·응답자별로 정돈해줘.
질문 순서를 보존하고, 대상자가 왜 그렇게 답변했는지와 사례·조건·제안을 충분히 남겨줘.
보고서 문체로 구어체만 정리하되 원문에 없는 의견은 추가하지 마.
종합 시사점은 본문과 분리하고, 이번에는 별도로 작성하지 마.
```

## 품질 점검
- 담당자 질문이 누락·통합되지 않았는지 확인
- 사람별 발언의 맥락과 견해 차이가 보존됐는지 확인
- 입장에 대한 이유/사례/조건·제안이 과도하게 줄지 않았는지 확인
- 제안이 확정·합의로 바뀌지 않았는지 확인
