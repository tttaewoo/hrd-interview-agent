# HRD 인터뷰 정리 Skill v3.1

인터뷰를 질문별 한 문단으로 요약하고, 동일한 구조의 Word 보고서로 제작하는 스킬입니다.

## 기본 산출물

- 파일 형식: Word 문서(.docx)
- 구성: 제목 → 인터뷰 개요 표(일시, 대상, 목적) → 질문별 답변
- 분량: 질문당 최대 한 문단, 일반적으로 2~4문장
- 내용: 핵심 답변과 그 이유, 이해에 필요한 사례나 조건
- 문체: ‘하였음’, ‘였음’ 또는 자연스러운 명사형

사전에 질문 목록을 제공하면 그 번호와 순서에 맞춰 답변을 배치합니다. 질문 목록이 없으면 실제 인터뷰 질문 순서를 따릅니다. 답변이 없는 질문은 생략하며, 사전 질문 번호를 임의로 다시 매기지 않습니다.

원문 설명, 녹취 기준, 타임스탬프, 미확인 정보는 결과물에 넣지 않습니다. 별도 인터뷰 배경은 만들지 않고 필요한 배경을 개요의 목적에 포함합니다. 가운데점을 이용한 나열을 피하며, 종합 시사점은 별도 요청이 있을 때만 작성합니다.

## 파일 구성

- 실행 기준: `.agents/skills/hrd-interview-summary/SKILL.md`
- 보고서 양식: `.agents/skills/hrd-interview-summary/references/report-template.md`

## 사용 방법

기존 체크아웃에서 위 스킬과 템플릿을 읽고 적용하도록 요청합니다. 다른 프로젝트에서는 `.agents/skills/hrd-interview-summary` 폴더를 프로젝트 루트의 `.agents/skills/` 아래에 배치합니다. 인터뷰 자료와 질문 목록을 함께 첨부하거나 대화에 입력합니다.

```text
$hrd-interview-summary
첨부한 인터뷰를 기존 스킬과 템플릿에 맞춰 Word 보고서로 정리해줘.
아래 질문 목록의 번호와 순서를 기준으로 하고, 질문별 답변은 최대 한 문단으로 요약해줘.

[질문 목록]
1. 팀에서 주로 수행하는 업무는 무엇인가요?
2. AI를 업무에 어떻게 활용하고 있나요?
3. 교육에서 다루었으면 하는 내용은 무엇인가요?

출력 파일명: 인터뷰_정리.docx
```

## 검수 기준

- 제공한 질문 목록과 보고서 순서가 일치하는지 확인
- 개요가 간단한 표이며 확인된 정보만 포함하는지 확인
- 질문마다 한 문단으로 핵심과 이유를 정리했는지 확인
- 응답자 구분과 의견의 차이를 유지했는지 확인
- 제안이나 예상을 확정된 사실로 바꾸지 않았는지 확인
- 원문 설명, 미확인 표기, 별도 배경, 불필요한 나열을 제거했는지 확인
- 실제 Word 문서에 표와 질문, 답변이 정상적으로 반영되었는지 확인
